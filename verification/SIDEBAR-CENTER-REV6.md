# Perataan ikon sidebar — Revisi 6

Kotak ikon navigasi kini memakai grid 22 × 22 px dengan ikon dan pseudo-element berbentuk block. Ini menghilangkan ruang baseline font yang sebelumnya membuat ikon 2,75 CSS px lebih tinggi daripada pusat highlight. Aturan yang sama berlaku untuk sidebar diperluas, diperkecil, dan menu Admin Panel. Bentuk, warna, dan ukuran ikon Tabler dipertahankan.

Pemeriksaan lokal menggunakan Microsoft Edge dengan font dan ikon asli, serta backend simulasi. Ketujuh ikon diperiksa pada kedua ukuran sidebar: selisih pusat vertikal kotak ikon terhadap highlight berubah dari −2,75 menjadi 0 CSS px. Screenshot kedua ukuran sidebar juga diperiksa secara visual. Hasil ini tidak menyatakan pengujian ulang keseluruhan fitur situs.

Semua sepuluh halaman memuat app.css dengan versi sidebar-center-6. Perubahan hanya pada salinan hasil; proyek D:/Project/ClouvenTwo-V2 dan arsip revisi sebelumnya tidak ditimpa.
